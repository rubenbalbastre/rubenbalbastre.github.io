# Rubén Balbastre personal website

Static personal website built with plain HTML generated by a small standard-library Python script. The generated site lives in `docs/` and is deployed to GitHub Pages by GitHub Actions, without Jekyll.

## Structure

- `build.py`: builds the static HTML site.
- `docs/`: generated website to publish from GitHub Pages.
- `pages/cv.md`: editable CV source, published at `/cv/`.
- `pages/blog_*.md`: editable blog post sources, published under `/blog/YYYY_MM/`.
- `assets/css/site.css`: source CSS copied into `docs/assets/css/site.css`.
- `assets/images/`: source images copied into `docs/assets/images/`.

## Local preview

```bash
python3 build.py
cd docs
python3 -m http.server 8000
```

Then open `http://127.0.0.1:8000`.

## Publishing on GitHub Pages

Push to `main`. The workflow in `.github/workflows/pages.yml` builds the site and publishes `docs/` automatically.

For the first deployment, open `Settings` > `Pages` in GitHub and set **Source** to **GitHub Actions**. The site will be published at `https://rubenbalbastre.github.io`.
