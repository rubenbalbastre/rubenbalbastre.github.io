# Rubén Balbastre personal website

Static personal website built with plain HTML generated by a small standard-library Python script. The generated site lives in `docs/`, so it can be served locally with Python and published on GitHub Pages without Jekyll.

## Structure

- `build.py`: builds the static HTML site.
- `docs/`: generated website to publish from GitHub Pages.
- `pages/cv.md`: editable CV source, published at `/cv/`.
- `pages/blog_*.md`: editable blog post sources, published under `/blog/YYYY_MM/`.
- `assets/css/site.css`: source CSS copied into `docs/assets/css/site.css`.
- `assets/images/`: source images copied into `docs/assets/images/`.

## Local preview

```bash
python3 build.py
cd docs
python3 -m http.server 8000
```

Then open `http://127.0.0.1:8000`.

## Publishing on GitHub Pages

1. Push the repository to `rubenbalbastre.github.io`.
2. In GitHub, open `Settings` > `Pages`.
3. Select `Deploy from a branch`, branch `main`, folder `/docs`.
4. The site will be published at `https://rubenbalbastre.github.io`.
